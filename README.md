# Firework
🎆 Firework — a relaxing, single-file HTML fireworks toy. Tap to light the night sky over a quiet lake 🌙 Choose colours 🎨 and burst shapes 💖⭐🌴, drift into slow motion 🐢, and let each burst ring a soft bell note 🔔 that harmonises with an ambient score 🎶 No install, no dependencies, no scores — just beauty. ✨ CC0 public domain.
